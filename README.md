# pm-mccabe-thiele
A McCabe-Thiele Simulation implemented in MATLAB, produced by Pouriya Mehrabani

The primary use of this program is to calculate the number of stages needed for a distillation column using the McCabe-Thiele method, where a sample graph is shown below.
